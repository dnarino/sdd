---
description: SDD step 4 — break the active plan into tasks with a validation table
---

Write `tasks.md` for the most recent spec in `specs/`.

1. Read `docs/sdd-guide.md` (section 5 and the `tasks.md` template in section 9), the spec, and the plan.
2. Write small tasks in build order. Each task gets the requirement(s) it covers (R?) and a "done when" check.
3. Add the validation table: one row per requirement, how it's checked, status ⏳ pending.
4. Check that every requirement is covered by at least one task. List any gaps.
5. Stop after writing the tasks. Don't write code.
