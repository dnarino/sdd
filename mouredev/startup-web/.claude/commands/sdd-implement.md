Implement the next task of the most recent spec in `specs/`.

1. Read `AGENTS.md`, `docs/constitution.md`, and the spec, plan, and tasks.
2. Take **only** the next unchecked task in `tasks.md`.
3. Write the code and its tests. Respect the plan's boundaries: for anything under "Ask first", stop and ask me.
4. Run the task's "done" check and the commands in "Al terminar cualquier tarea" of `AGENTS.md`.
5. If everything passes, mark the task `- [x]`. If not, fix it or tell me what's blocking.
6. If the spec or plan is wrong or missing something, stop and tell me. Don't change them silently.
7. Stop after one task and summarize what you did and what's next.
