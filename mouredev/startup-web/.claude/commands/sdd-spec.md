Write a new spec for this idea: $ARGUMENTS

1. Read `docs/constitution.md` and `docs/sdd-guide.md` (section 3 and the `spec.md` template in section 9).
2. Look in `specs/` for the highest number and create `specs/<next NNN>-<short-kebab-name>/spec.md`.
3. Use EARS for the requirements (R1, R2…) and include the `IF … THEN` error cases.
4. No technology in the spec. Fill in "Out of scope". Put every doubt in "Open questions".
5. Stop after writing the spec. Don't write the plan. Show me a short summary and the open questions.
